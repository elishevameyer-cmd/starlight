## 🚀 איך להתחיל?

### שלב 1: דף הנחיתה (הזמנות)
1. פתח את `01_landing-page.html` בדפדפן
2. ערוך את התמונות (הוסף תמונות אמיתיות של ישי)
3. ערוך את הטקסטים (עדכן שמות הופעות, תאריכים, מחירים)
4. בדוק ב-mobile ודסקטופ
5. התקן טופס הזמנה (Stripe / PayPal / Google Forms)
6. העלה לשרת

### שלב 2: תוכן אינסטגרם
1. קרא את `05_instagram-content.md`
2. בנה את ה-Bio בסגנון המוצע
3. צור את 5 ה-Highlights
4. כתוב פוסט ראשון בעקבות Calendar
5. בתוך שבוע: 3-4 פוסטים

### שלב 3: שיפור (בהתמשכות)
1. בדוק את `04_conversion-optimization.md`
2. התקן Google Analytics
3. קבול נתונים בשבועות ראשונים
4. בצע A/B tests לפי ה-template
